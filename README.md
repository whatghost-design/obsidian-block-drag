# 區塊拖曳 Block Drag

像 Notion 一樣，在 Obsidian 編輯器裡每一行前面都有 ⋮⋮ 把手，可以拖曳搬移區塊。

- 清單項目連同子項目一起搬
- 標題連同整個章節（到下一個同級或更大的標題為止）一起搬
- 程式碼區塊、表格、引言／Callout、公式整塊搬
- 放下時往右拖 → 變成上一項的子項目
- 點一下把手 → 上移、下移、複製一份、刪除

只支援編輯模式（即時預覽／原始碼），桌面版限定。

## 安裝

1. 安裝社群外掛 **BRAT**
2. BRAT 設定 → Add beta plugin → 貼上這個 repo 的網址
3. 到「第三方外掛」打開「區塊拖曳 Block Drag」
